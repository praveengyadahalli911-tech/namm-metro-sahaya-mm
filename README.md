# Namma Metro Sahaya

**Namma Metro Sahaya** is a smart, offline-first transit companion app for Bengaluru's BMRCL network. It features an intuitive, premium dark-mode interface that allows commuters to seamlessly calculate dynamic fares, explore live route visualizations, and navigate the metro system with ease.

### 🚀 Live Demo
**[https://namm-metro-sahaya.web.app](https://namm-metro-sahaya.web.app)**

---

### 🛠 Technologies Used

**Core Stack**
*   **Flutter:** Cross-platform UI toolkit used to build the beautiful, compiled application.
*   **Dart:** The primary programming language powering the app's logic and architecture.

**Backend & Cloud**
*   **Firebase Hosting:** Used for fast, secure, and free deployment of the Flutter Web application.
*   **Firebase Core / Cloud Firestore:** Integrated for real-time capabilities and backend services.
*   **Google Generative AI (Gemini):** Used to power the intelligent Natural Language Query system (`google_generative_ai`).

**Key Packages & Libraries**
*   **Provider:** For clean and scalable State Management.
*   **Google Fonts:** Specifically providing premium typography (like `Inter` and `Outfit`).
*   **Flutter Animate:** Used to create the smooth, premium micro-animations and transitions throughout the UI.
*   **Connectivity Plus:** Actively monitors network status to enable the app's seamless "offline-first" functionality.
*   **Shared Preferences:** Handles local caching for offline data storage.
*   **String Similarity:** Powers the fuzzy search functionality so users can find stations even if they misspell them. 

---

### 💡 Problem Statement
Daily commuters on the Namma Metro (BMRCL) network often face challenges in planning their routes, calculating accurate fares, and accessing station information—especially when underground or in areas with poor cellular network connectivity. Existing solutions rely heavily on constant internet access and often lack an intuitive, fast, and accessible interface. 

There is a need for a reliable, offline-first transit companion application that provides dynamic route planning, accurate fare calculation, and seamless navigation capabilities to commuters, ensuring they have uninterrupted access to critical travel information regardless of their network status.
