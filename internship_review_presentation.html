05
The Problem

For many people coming to Bengaluru, using Namma Metro is confusing:

🚩 Navigation

Hard to find the correct platform

🔄 Interchanges

Interchange stations (Majestic) are confusing

🚪 Exits

Don't know which gate leads to their destination

📖 Guidance

No simple, step-by-step guidance available

06
The Solution

Namma-Metro Sahaya

Designed specifically for first-time and non-technical users.

  • Simple, jargon-free directions
  • Visual step-by-step journey guidance
  • Localized support (English & Kannada)
  • Context-aware exit information
07
Key Features

🚉 Easy Route Search

Pick source and destination; see the best path instantly.

🚶 Step-by-Step Guide

Clear instructions like "Go to Platform 2" or "Change line at Majestic".

🚪 Exit Help

Identifies correct gates for bus stands, hospitals, and landmarks.

🎫 Travel Info

Real-time display of ticket prices and total travel time.

08
Technical Implementation

Frontend

Kotlin + Jetpack Compose. Step-based UI for maximum simplicity.

Storage

Room Database for offline support. Glide for image management.

Routing Logic

Graph-based network processing (Nodes: Stations, Edges: Tracks).

AI Integration

Google Gemini for generating natural language navigation instructions.
